# PromptLab — Critical Generative AI Literacy

> A gamified learning prototype for developing critical generative AI literacy, prompt-engineering skills, and responsible AI use.

## Overview

PromptLab is an interactive educational prototype designed to help students develop practical and critical skills for working with generative AI.

The project explores an alternative to purely instructional approaches to AI literacy: instead of only explaining prompting principles and AI limitations, learners interact with structured activities, compare AI-related scenarios, evaluate generated information, and reflect on their learning.

The prototype is designed around the learning cycle:

**Predict → Prompt → Compare → Verify → Reflect**

---

## Motivation

Generative AI tools are increasingly used by university students for learning, writing, research and problem solving.

However, effective AI use involves more than knowing how to write a prompt. Students also need to understand:

- how prompt structure influences outputs;
- why fluent AI-generated information may still be unreliable;
- which claims require verification;
- how to communicate task, context, audience and constraints;
- and how to reflect critically on their interaction with AI.

PromptLab was designed as a small-scale prototype exploring these learning goals.

---

## Core Learning Activities

### 1. Prompt Builder

Learners construct a structured prompt by selecting:

- Context
- Task
- Audience
- Constraints

The activity aims to make prompt structure visible and actionable.

### 2. AI Output Detective

Learners inspect fictional AI-generated responses and identify why claims should not automatically be trusted.

The central learning principle is:

**Generate ≠ Verify**

### 3. Prompt Battle

Learners compare a vague prompt with a more structured prompt and predict which one is likely to produce a more useful response.

The activity emphasises that better prompting is not simply about writing longer prompts, but about communicating relevant information clearly.

### 4. Reflection

Learners write a short reflection about what they learned and how their approach to AI might change.
